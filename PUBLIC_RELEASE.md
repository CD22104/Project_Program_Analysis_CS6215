# Public release boundary

The author explicitly authorized code/evidence publication while excluding the personal
name, student identifier and report. This checkout is a sanitized snapshot with a
separate public history. The full original project and history are retained locally.

Report PDF/source files and administrative report/publication logs are omitted.
Reviewer names in annotations are replaced by an anonymous author role. Historical
private-project commit references are omitted. API keys, course PDFs, unlicensed real
notebook sources/outputs, original model request bodies and author alarm HTML remain
excluded. Scientific labels, predictions, model summaries, failures, usage and frozen
implementation files are preserved. Annotation hashes are recomputed after redaction.

The public rebuild creates scratch table fragments but does not include or recreate
the signed report. Public packaging includes tracked files only and excludes `report/`.
Statements in historical experiment notes about a report or local ZIP refer to the
private deliverable, not files distributed in this checkout.
